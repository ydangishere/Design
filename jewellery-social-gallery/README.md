# Maison Studies — Luxury Jewellery Facebook Poster Gallery

**Live site:** https://ydangishere.github.io/Design/jewellery-social-gallery/

An independent luxury-jewellery social poster concept gallery with **10 AI-generated image posters**, each designed for **1080 × 1350 px (4:5)** Facebook/Instagram feeds. The gallery has a warm ivory/cream background and each jewellery house uses a distinct creative direction.

Click a poster to view it large. The **TẢI POSTER PNG** button saves an individual **1080 × 1350 PNG** file. Since these are raster AI poster artworks, the SVG download is hidden.

## Design guideline

- **Minimalism** — ivory, negative space, one hero product
- **Art Deco** — geometric precision, gold details, symmetry
- **Editorial** — cinematic jewellery photography, magazine typography
- **Art Nouveau** — poetic botany, pearls, romantic curves
- **3D / CGI** — sculptural forms, authentic-looking metals, realistic gems

Keep imagery product-first, refined, brand-distinct and mobile readable. All output represents independent work inspired by broad brand aesthetics, not an official campaign or brand partnership.

## Run & publish

The site is self-contained in `index.html`; it runs as a static GitHub Pages folder site on the repository's `master` branch. Open the live URL or open `index.html` locally. There is no framework or build step.
