# Maison Studies — Jewellery Social Poster Gallery

An independent, responsive mini-gallery with **10 original SVG social-media poster concepts** inspired by distinctive visual identities associated with iconic jewellery houses.

**Live site:** https://ydangishere.github.io/Design/jewellery-social-gallery/

## Poster set
Tiffany & Co. · Cartier · Van Cleef & Arpels · Bvlgari · Harry Winston · Graff · Chopard · Piaget · Buccellati · Mikimoto.

## Features
- Ten original vector compositions, each with a different art direction, palette, typography and jewellery illustration.
- Responsive grid and fullscreen poster viewer.
- Download each poster as **1080 × 1350 PNG** (Instagram portrait 4:5) or editable **SVG**.
- No external product images or UI framework. CSS uses a Google Fonts import only for site typography; poster text has safe local font fallbacks.
- Keyboard navigation: left/right in viewer, Esc to close.

## Run
Open `index.html` in any modern browser. The site is compatible with GitHub Pages and requires no build step.
